# 👨‍💻 Meu Site Pessoal

Bem-vindo ao meu site pessoal! Este projeto foi desenvolvido com o objetivo de apresentar um pouco sobre mim, minhas habilidades, interesses e minha trajetória no universo da tecnologia.

## 🌐 Sobre o projeto

O site funciona como uma apresentação pessoal, reunindo informações sobre minha identidade, conhecimentos e interesses acadêmicos e profissionais. Além disso, representa uma oportunidade de aplicar e desenvolver meus conhecimentos em desenvolvimento web.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização e organização visual.
- **Python:** execução da aplicação e inicialização do servidor local.

## 📂 Estrutura do projeto

```text
site pessoal/
├── templates/

│   │   ├── icons/
│   │   └── images/
│   ├── index.html
│   └── styles.css
├── README.md
├── TERMS.md

```

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Kauan-BRL/site-pessoal
   ```

2. Entre na pasta do projeto:

   ```bash
   cd site pessoal
   ```

3. Execute a aplicação Python:

   ```bash
   python app.py
   ```

4. Acesse o endereço local disponibilizado no terminal pelo navegador.

## 🎯 Objetivo

Este projeto tem como finalidade construir uma identidade digital, demonstrar meus conhecimentos em desenvolvimento web e documentar minha evolução na área da tecnologia.
